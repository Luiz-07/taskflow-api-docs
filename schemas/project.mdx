# Project

Represents a project in the TaskFlow API.

Properties

| Parameter | Type | Nullable | Description |
|---|---|---|---|
| `project_id` | string (UUID) | No | Unique identifier of the project. Generated automatically. |
| `name` | string | No | The name of the project. |
| `description` | string | Yes | An optional description of the project |
| `created_at` | string (date-time) | No | Timestamp of when the project was created. |

## Example

```json
{
 "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
 "name": "API Documentation Revamp",
 "description":  "Rewriting all public-facing API docs for v2.",
 "created_at": "2025-05-12T10:30:00.000Z"
}
```
