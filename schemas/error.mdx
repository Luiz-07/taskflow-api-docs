# Error

Represents a error in the TaskFlow API.

# Properties

| Parameter | Type | Nullable | Description |
|---|---|---|---|
| `Error` | string | No | Short error type. |
| `Menssage` | string | No | Human-readable explanation of the error. |

#example

```json
{
 "Error": "Not Found",
 "Menssage": "No project found with project_id 'abc123'"
}
```
