# Quickstart

This guide walks you through the basic workflow of the TaskFlow API, from creating a project to managing its tasks.

## Prerequisites

Before getting started, make sure you have:

- A valid TaskFlow API key.
- An HTTP client, such as cURL or Postman.

## Step 1: Create a project

Before creating tasks, you must create a project.

**Endpoint:** `POST /projects`

```bash
curl -X POST "https://test-writechoice.onrender.com/projects" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My First Project",
    "description": "A project created using the TaskFlow API"
  }'
```

The API returns the created project, including its `project_id`.

Save this ID because you will need it to create tasks.

## Step 2: Create a task

Now use the `project_id` returned in the previous step.

**Endpoint:** `POST /tasks`

```bash
curl -X POST "https://test-writechoice.onrender.com/tasks" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "YOUR_PROJECT_ID",
    "title": "Create API documentation",
    "description": "Write the first version of the documentation"
  }'
```

The API returns the created task, including its `task_id`.

## Step 3: List project tasks

To retrieve all tasks belonging to a project, use:

**Endpoint:** `GET /projects/{project_id}/tasks`

```bash
curl -X GET "https://test-writechoice.onrender.com/projects/YOUR_PROJECT_ID/tasks" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The response contains the project ID, the total number of tasks, and the tasks array.

## Step 4: Update a task

To update a task, use its `task_id`.

**Endpoint:** `PATCH /tasks/{task_id}`

```bash
curl -X PATCH "https://test-writechoice.onrender.com/tasks/YOUR_TASK_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "in_progress"
  }'
```

Available task statuses:

| Status | Description |
|---|---|
| `pending` | Task not started |
| `in_progress` | Task in progress |
| `done` | Task completed |

## Step 5: Delete a task

To permanently delete a task, use:

**Endpoint:** `DELETE /tasks/{task_id}`

```bash
curl -X DELETE "https://test-writechoice.onrender.com/tasks/YOUR_TASK_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The API returns a confirmation message when the task is deleted.

**Warning:** Deleting a task is permanent and cannot be undone.
