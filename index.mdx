# TaskFlow API

The TaskFlow API is a simple task management API that allows you to create projects, manage tasks, update task statuses, and delete tasks.

## What can you do?

With the TaskFlow API, you can:

- Create projects to organize your work.
- Create tasks inside existing projects.
- List all tasks belonging to a project.
- Update task information and status.
- Delete tasks.

## How does it work?

The API follows a simple workflow:

1. Create a project.
2. Save the `project_id` returned by the API.
3. Create tasks using that `project_id`.
4. List or update tasks as needed.
5. Delete tasks when they are no longer needed.

## Base URL

All API requests are sent to:

```text
https://test-writechoice.onrender.com/
```

## Authentication

The API requires a valid Bearer token to authenticate requests.

You must include your API key in the `Authorization` header.

For example:

```http
Authorization: Bearer YOUR_API_KEY
```

See the [Authentication](guides/authentication) guide for more details.
